Canny Edge Detection The classic five-stage pipeline that turns an image into clean, thin, connected edges.

Canny finds edges in five steps — click each thumbnail to enlarge it:

  1. Blur with a Gaussian to suppress noise (σ controls how much).
  2. Gradient via Sobel — bright where intensity changes fastest.
  3. Thin by non-maximum suppression: keep only ridge tops, so edges become 1px wide.
  4. Hysteresis: pixels above the high threshold are strong (white); pixels above the low threshold survive only if connected to a strong one (green) — otherwise they're dropped (red).
  5. Edges: the final map (strong + kept-weak).

Two thresholds beat one: a single threshold either breaks real edges or lets noise through. Hysteresis keeps faint edge continuations while rejecting isolated noise.
