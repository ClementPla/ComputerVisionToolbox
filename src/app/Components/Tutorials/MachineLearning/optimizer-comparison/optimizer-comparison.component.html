Optimizer Theory

SGD

θ ← θ - η∇f(θ)

Momentum

v ← βv - η∇f(θ)

θ ← θ + v

RMSProp

E[g²] ← βE[g²] + (1-β)g²

θ ← θ - η·g/√E[g²]

Adam

m ← β₁m + (1-β₁)g

v ← β₂v + (1-β₂)g²

θ ← θ - η·m̂/√v̂

Key Differences

  • SGD: Simple, can oscillate
  • Momentum: Accelerates in consistent directions
  • AdaGrad: Adapts LR per parameter
  • RMSProp: Fixes AdaGrad's decay
  • Adam: Combines momentum + RMSProp
