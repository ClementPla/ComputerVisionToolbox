Convolution Basics

Kernel Size

The dimensions of the filter window. Common sizes: 3×3, 5×5, 7×7.

Stride

Step size when sliding the kernel. Stride > 1 reduces output size.

Padding

Zeros added around input. "Same" padding preserves spatial dimensions.

Dilation

Spacing between kernel elements. Dilation > 1 increases receptive field without adding parameters.

Output Size Formula

O = ⌊(I + 2P - D(K-1) - 1) / S⌋ + 1

I = input size
K = kernel size
S = stride
P = padding
D = dilation

Effective Kernel Size

With dilation d, effective size = d(k-1) + 1
