How Tokenization Works

Text is split into tokens (words or subwords). Special tokens like [CLS] are added for classification tasks. Register tokens act as scratch space for the model to store intermediate computations.

Images are divided into patches ({{ patchSize }}×{{ patchSize }} pixels each). Each patch becomes a token, similar to words in text. The [CLS] token aggregates information from all patches for classification.

Self-Attention Formula

Attention(Q, K, V) = softmax(Q × KT / √d) × V

Each token computes Query (Q), Key (K), and Value (V) vectors. The attention weight between tokens is the dot product of Q and K, scaled and normalized with softmax.

Why Multiple Heads?

Each attention head can learn different patterns:

  • Some heads focus on nearby tokens (local context)
  • Others capture long-range dependencies
  • Some learn syntactic relationships (subject-verb)
  • Others learn semantic relationships (word meaning)

The outputs of all heads are concatenated and projected back to the model dimension.
