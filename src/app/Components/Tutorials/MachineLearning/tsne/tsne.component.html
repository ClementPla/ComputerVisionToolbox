t-SNE Flatten high-dimensional data to 2D while keeping neighbours together.

t-SNE turns the neighbourhoods of a high-dimensional dataset into a 2D map. For every pair of points it defines an affinity pij (high for near points, ~0 for far ones), then arranges the 2D points so their affinities qij match — by minimising the mismatch KL(p ‖ q) with gradient descent.

Hover a point in the 2D map: its true neighbours from the original 3D space light up in both views, with springs drawn in 2D. If t-SNE worked, those springs are short — neighbours in 3D landed next to each other in 2D.

Perplexity is roughly “how many neighbours each point pays attention to.” Small values preserve tight local clumps; large values keep more global structure. Re-run to compare.

Caveat: in a t-SNE map the sizes of clusters and the gaps between them are not meaningful — only who-is-next-to-whom is. It is also stochastic, so each run differs.
