Vanilla RNN Cell

ht = tanh( Wh·ht-1 + Wx·xt + b)
yt = ht (or Wy·ht + by for projection)

Vanilla RNN processes sequences by maintaining a hidden state ht that carries information from previous time steps. The same weights are shared across all steps.

⚠️ Vanishing Gradient Problem: During backpropagation through time, gradients are multiplied repeatedly by Wh. If eigenvalues < 1, gradients vanish; if > 1, they explode.

LSTM Cell

ft = σ(Wf[ht-1, xt] + bf)
it = σ(Wi[ht-1, xt] + bi)
c̃t = tanh(Wc[ht-1, xt] + bc)
ot = σ(Wo[ht-1, xt] + bo)
ct = ft ⊙ ct-1 + it ⊙ c̃t Cell state
ht = ot ⊙ tanh(ct) Hidden state

LSTM solves the vanishing gradient problem with a cell state (the horizontal line at top) that acts as a highway for gradient flow.

The forget gate decides what to discard, the input gate and candidate determine what new info to add, and the output gate controls what part of the cell state becomes the output.

RNN Architectures

Many-to-One (Sequence Classification)

Use cases: Sentiment analysis, document classification

Process entire sequence, take final hidden state hT as output.

Sequence-to-Sequence (Encoder-Decoder)

Use cases: Machine translation, summarization, chatbots

Encoder compresses input into a context vector, decoder generates output sequence.

Stacked (Deep) RNN

Use cases: Complex sequence modeling, speech recognition

Multiple RNN layers stacked. Each layer learns increasingly abstract temporal features.

Bidirectional RNN

Use cases: NER, POS tagging, when future context helps

Two RNNs: one forward, one backward. Outputs concatenated: ht = [ht→ ; ht←]

Quick Reference

RNN Parameters

  • Wh: hidden × hidden
  • Wx: hidden × input
  • b: hidden

Total: O(h² + h·d)

LSTM Parameters

  • 4 gate weight matrices
  • 4 bias vectors

Total: 4× more params than RNN

Architecture Choice

  • Many-to-One: Classification
  • Seq2Seq: Translation
  • Stacked: Complex patterns
  • Bidirectional: Full context

Key Insight

RNN reuses the same weights at every time step — this is called weight sharing.

The cell state allows gradients to flow unchanged (additive updates), solving vanishing gradients.

All architectures use the same basic RNN/LSTM cell — they differ in how cells are connected.
