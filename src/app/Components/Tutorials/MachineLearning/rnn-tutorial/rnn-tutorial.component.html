Hidden State as Memory

The hidden state ht is the network's "memory". It encodes information about all previous inputs. In vanilla RNN, the hidden state is computed as: ht = tanh(Wih·xt + Whh·ht-1) Green = positive, Red = negative.

Gates Control Information Flow

LSTM uses 4 gates to control what information to forget, what to store, and what to output. All gates use sigmoid (0-1 range) except the candidate which uses tanh (-1 to 1).

GRU simplifies LSTM with only 2 gates: Reset (controls how much past info to ignore) and Update (controls balance between old and new).

The Cell State Highway

The cell state ct acts as a "highway" that allows gradients to flow unchanged over long sequences. The forget gate removes irrelevant info, while the input gate adds new info. This solves the vanishing gradient problem that plagues vanilla RNNs.
