📊 Model

A weighted sum of K Gaussian distributions. Each component has its own mean μ, variance σ², and weight π.

🎯 Parameters

K = {{ numComponents }} components. Weights sum to 1. Dashed lines show individual components.

📈 Training

Typically fitted using the EM algorithm (Expectation-Maximization) to find optimal parameters.

📊 Method

Places a kernel (Gaussian) at each data point and sums them. Non-parametric — no assumption about the underlying distribution.

🎚️ Bandwidth

h = {{ bandwidth.toFixed(2) }} controls smoothing. The only hyperparameter to tune. Critical for good estimation.

📐 Bias-Variance

Small h → low bias, high variance. Large h → high bias, low variance. Optimal h balances both.
GMM Density
p(x) = ∑Kk=1 πk · 𝒩(x | μk, σk²)
where πk are mixing weights with ∑πk = 1
KDE Density
p̂(x) = 1n·h ∑ni=1 K(x − xih)
where K is the kernel function (here Gaussian) and h is the bandwidth

2D visualization: The heatmap shows density values. Contour lines indicate regions of equal density. Colored circles mark component centers, dashed circles show 1σ regions. Each data point contributes a 2D Gaussian kernel to the estimate.

Quick Reference

Density Estimation

Estimate the probability distribution p(x) from observed samples.

Goal: Approximate the true underlying distribution

GMM Properties

  • Parametric: Assumes Gaussian components
  • Generative: Can sample new data
  • Clustering: Soft cluster assignments

KDE Properties

  • Non-parametric: No distribution assumption
  • Consistent: Converges to true density
  • Flexible: Can model any shape

Common Kernels

  • Gaussian: Smooth, unbounded
  • Epanechnikov: Optimal MSE
  • Uniform: Box kernel

This demo uses Gaussian kernel

Bandwidth Selection

  • Silverman's rule: h ≈ 1.06σn−1/5
  • Cross-validation: Minimize error
  • Plug-in: Estimate optimal h
