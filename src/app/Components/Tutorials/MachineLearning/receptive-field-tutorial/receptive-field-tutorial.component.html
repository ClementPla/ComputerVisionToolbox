Receptive Field

Theoretical RF

The total area in the input that can mathematically influence a single output neuron.

Effective RF

In practice, central pixels contribute more than edge pixels (Gaussian distribution). Typically ~70% of theoretical RF.

RF Formula

RF(n) = RF(n-1) + (k_eff - 1) × j(n-1)

j(n) = j(n-1) × s(n)

k_eff = effective kernel
s = stride
j = jump (cumulative stride)

Why Stride Matters

Stride increases the jump (j), which is the cumulative stride from input to current layer. A larger jump means subsequent layers add more to the RF.

Example: With j=2, a 3×3 kernel adds (3-1)×2 = 4 to RF instead of 2.

Key Insights

  • Deeper networks → larger RF
  • Stride > 1 → faster RF growth
  • Dilation → larger RF without more params
  • Pooling → efficient RF expansion

Why It Matters

The RF determines what context each output neuron "sees". For tasks like segmentation, the RF should cover relevant context (e.g., entire object, not just edges).
