SVM Theory

Decision Function

f(x) = Σ αᵢyᵢK(xᵢ,x) + b

Support Vectors

Points with αᵢ > 0. They lie on or within the margin.

Margin Violation

When yᵢf(xᵢ) < 1, the point is inside the margin or misclassified.

Kernels

  • Linear: K(x,z) = x·z
  • RBF: K(x,z) = exp(-γ||x-z||²)

Parameter C

Trade-off between margin size and training errors. High C = hard margin.
