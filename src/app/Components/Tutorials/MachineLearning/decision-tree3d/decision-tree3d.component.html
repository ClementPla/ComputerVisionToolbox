💡 Theory

Decision trees recursively partition the feature space using axis-aligned splits (thresholds on single features).

Gini Index:

G = 1 - Σ p²ᵢ

Measures impurity. G=0 means pure node.

Cross-Entropy:

H = -Σ pᵢ log₂(pᵢ)

Information-theoretic impurity measure.

At each node, the algorithm finds the split that maximizes information gain (reduces impurity the most).

Note: Decision trees create rectangular partitions, which may not align well with the true class boundaries in complex datasets.
