Autoregressive Language Modeling

Joint Probability Decomposition
P(x1:T) = ∏Tt=1 P(xt | x<t)
{{ token }}
→ {{ samplePredictions[i] }}

Each token predicts the next. Every prediction depends on ALL previous tokens.

🎯 Objective

Predict the next token given all previous tokens. The model learns P(xt | x<t).

🔗 Chain Rule

Joint probability factorizes left-to-right. This is the foundation of GPT, LLaMA, and all decoder-only models.

⚡ Training Signal

Cross-entropy loss at every position. One forward pass = T prediction tasks.

Autoregressive means the model generates one token at a time, each conditioned on all previous tokens. This is fundamentally different from models like BERT that see the entire sequence at once (bidirectional).

Transformers use masking to prevent tokens from "seeing the future" during training. The attention scores for future positions are set to −∞, which becomes 0 after softmax.

This allows parallel computation of all positions during training — a huge speedup compared to RNNs. All T predictions are computed in a single forward pass.

📝 Inputs are ground truth tokens, not model predictions

📚 Teacher Forcing

During training, we feed the ground truth tokens as input, not the model's own predictions. This stabilizes training.

🔄 Sequential Nature

RNN must process tokens one-by-one due to hidden state dependency. No parallelization possible within a sequence.

🎯 Built-in Causality

No masking needed! The recurrent structure naturally ensures each output only depends on past inputs.

RNNs are inherently causal — the hidden state ht only contains information from x1 to xt. No explicit masking is required.

Drawback: Sequential processing means we can't parallelize across time steps. Training on long sequences is slow compared to Transformers.

🤖 Transformer Inference

  • ⚠ Still sequential generation
  • ✓ KV-cache avoids recomputation
  • ✓ Only compute new token's attention
  • ✓ Still parallelizes across batch
Complexity: O(T) generation steps, but each step is O(T) for attention

🔄 RNN Inference

  • ⚠ Same as training: sequential
  • ✓ Constant memory per step
  • ✓ O(1) compute per step
  • ✗ No parallel across batch easily
Complexity: O(T) steps, O(1) per step (just h update)
Key Insight: During inference, both models are sequential! The Transformer's training advantage disappears. This is why RNN-style models (Mamba, RWKV) are making a comeback for long-context inference.
