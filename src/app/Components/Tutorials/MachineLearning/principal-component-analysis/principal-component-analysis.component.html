Principal Component Analysis (3D) Explore how PCA finds directions of maximum variance. Move the projection vector and observe how the projected variance changes.

Principal Component Analysis (PCA) is a statistical technique used to identify the directions (principal components) in which data varies the most. In this interactive tutorial, you can manipulate a projection vector in 3D space and observe how it aligns with the principal components of a synthetic dataset.

  • Adjust the polar (θ) and azimuthal (φ) angles to change the orientation of the projection vector.
  • Observe how the projected variance of the data changes as you move the vector.
  • Try aligning the vector with each principal component (PC1, PC2, PC3) using the buttons provided.
