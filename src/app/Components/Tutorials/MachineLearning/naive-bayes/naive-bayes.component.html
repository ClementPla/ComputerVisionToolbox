Gaussian Naive Bayes A generative classifier: model each class, then ask which one most likely produced the point.

Bayes' rule says the probability a point belongs to a class is proportional to how likely that class is to generate it:

P(class | x, y) ∝ P(class) · p(x | class) · p(y | class)

The “naive” part is that last step: it assumes the features are independent, so the 2D likelihood is just the product of a bell curve along x and a bell curve along y. That is why each class's ellipse is axis-aligned — no tilt.

Drag the ✚ marker. The panel shows each class's prior, its two per-axis likelihoods Lx, Ly, and the resulting posterior. Watch a far-away axis dominate: one tiny likelihood is enough to rule a class out.
